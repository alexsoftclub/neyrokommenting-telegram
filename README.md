# Нейрокомментинг в Telegram: комментарии под постами, которые пишет нейросеть

Нейрокомментинг - это комментарии под постами Telegram-каналов, текст которых нейросеть составляет по содержанию каждого конкретного поста. В **AlexSoftClub** он встроен в задачу **19 Комментинг/НейроКомментинг**: аккаунт ловит свежий пост, передаёт его текст нейросети вместе с вашим заданием и публикует ответ в обсуждении. Такой комментарий звучит как реплика живого читателя, а не как шаблон.

## Как работает нейрокомментинг

1. Вы один раз подключаете нейросеть в пункте **24 Настройки LLM API** - её используют все ИИ-задачи программы.
2. В таблицу `19 4 Комментинг комментарии` вписываете задания, каждое начинается с `GPT:`.
3. Аккаунт отслеживает каналы, на которые подписан, и подхватывает новый пост с открытыми комментариями.
4. Программа выбирает случайное задание и сама дописывает в конец запроса текст поста: получается "ваше задание: текст поста".
5. Нейросеть возвращает комментарий. Если в нём есть слово из таблицы `19 3`, он не отправляется.
6. Готовый текст уходит в обсуждение, а история пишется в `19 6`.

## Возможности

- **Несколько заданий.** Каждая строка в `19 4` - отдельный промпт, для поста выбирается случайный; их можно смешивать с готовыми текстами.
- **Нейросеть и при редактировании.** В режиме "Редактировать комментарии" первым ставится эмодзи, а через паузу он меняется на строку из `19 5`. Там тоже можно писать `GPT:` - финальный текст сгенерирует нейросеть.
- **Контроль расходов.** Настройка "Лимит запросов к LLM за запуск" ограничивает число обращений к нейросети на всех аккаунтах вместе.
- **Любой OpenAI-совместимый сервис:** OpenAI, OpenRouter, VseLLM, DeepSeek, Groq, Mistral или свой шлюз. Claude и Gemini - только через посредника вроде OpenRouter.

### Как писать задания

Задание описывает тон, длину и цель. Примеры для `19 4`:

```
GPT: Напиши короткий комментарий по теме поста, тон - опытный трейдер. Без воды, 1-2 предложения, на языке поста.
GPT: Слегка поспорь с автором поста, аргументируй фактом из текста. Вежливо, без токсичности.
```

Префикс `GPT:` пишется латиницей в начале строки - иначе задание уйдёт в чат как обычный текст.

## Настройки

Подключение нейросети (пункт 24):

| Поле | Что вставить |
|------|--------------|
| URL API агрегатора | Адрес API без `/chat/completions`, можно с `/v1` в конце |
| LLM API ключ | Ключ из кабинета сервиса |
| LLM модель | Точный id модели, например `gpt-4o-mini` или `deepseek-chat` |

Параметры самой задачи 19:

| Настройка | Рекомендация |
|-----------|--------------|
| Лимит запросов к LLM за запуск (0 - без лимита) | `0` или, например, `2000` |
| Лимит комментариев на аккаунт | `30-50` |
| Задержка перед комментированием (сек) | `20-60` |
| Редактировать комментарии (1 - Да / 2 - Нет) | `2` для начала |

## Ограничения и безопасность

- Без URL, ключа и модели задача не стартует и показывает подсказку.
- Ошибка HTTP 401 - неверный ключ, 404 - неверный id модели, 429 - слишком частые запросы. Пустой ответ - неверная модель или пустой баланс.
- При флуд-ограничении аккаунт отдыхает 1 час, после третьего флуда - сутки, потом продолжает сам.

1. Подпишите аккаунты на целевые каналы задачей **8 Подписка на чаты/каналы**.
2. В главном меню кликните мышкой **24 Настройки LLM API**, заполните три поля кнопками **"Вставить"** и **"Сохранить"**, затем **"Назад"**.

## Частые вопросы

### Что такое нейрокомментинг в Telegram?
Это автоматические комментарии под постами каналов, которые нейросеть пишет по тексту поста. Каждый ответ уникален и связан с темой публикации. Читатели обсуждения переходят в профиль автора, а оттуда - в ваш канал.

### Какую нейросеть подключить для нейрокомментинга?
Подойдёт любой сервис с OpenAI-совместимым API: OpenAI, OpenRouter, VseLLM, DeepSeek и другие. В AlexSoftClub достаточно трёх полей в пункте "24 Настройки LLM API", и ключ работает во всех ИИ-задачах.

### Почему в обсуждение ушёл сам текст задания?
Строка в `19 4` не начинается с префикса `GPT:` или в нём опечатка. Префикс должен стоять в самом начале строки, латиницей.

### Как не потратить лишнее на нейросеть?
Задайте "Лимит запросов к LLM за запуск" и "Лимит комментариев на аккаунт". Первый считает обращения всех аккаунтов вместе, второй - комментарии одного аккаунта.
